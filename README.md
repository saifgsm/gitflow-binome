# GitFlow en binôme

**Binôme : Sifeddine Gouasmia & Roland Dansou**

## Description

Petit site web réalisé à deux pour mettre en pratique le workflow **GitFlow** : branches de fonctionnalité, commits, pull requests et merges.

## Organisation

- `main` : version stable du site.
- `feature/accueil` : page d'accueil (Sifeddine), intégrée via la pull request #1.
- La page de contact est réalisée par Roland.

Chaque fonctionnalité est développée sur sa propre branche, puis intégrée à `main` par une pull request.

## Lancer le projet

Ouvre le fichier `index.html` dans ton navigateur.

## Technologies

HTML · Git · GitHub
